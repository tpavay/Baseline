Product decisions shown

Draft ownership is visible

An import started from a plan day creates a draft owned by that day. The plan row is the resume point. Starting an import on another day starts a new draft.

Workouts and templates stay distinct

“Create one-time workout” builds only Wednesday's scheduled workout. “Choose or create template” opens the searchable library, where the top-right plus starts a reusable template.

Structure, not duplicated rows

The 3 x 13-minute tempo is a 3-round group. The EMOM is a 14-minute alternating group. Burpee to Plate remains one prescription inside that repeated group.

Ordinary editor controls

Blocks and groups disclose from the leading edge. Exercise menus stay on the right. Added set rows swipe left to delete.

Choose the import structure

My recommendation is the first option because it preserves the source card's hierarchy and uses native repeated groups for 3 rounds and EMOM x14.
